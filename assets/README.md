# First Minds assets

Product assets are grouped by their role:

- `branding/icon.png` — square production app icon artwork.
- `branding/adaptive-icon-foreground.png` — 1024×1024 RGBA Android foreground derived from the existing First Minds hand mark, with transparent padding for adaptive masks.
- `branding/splash.png` — portrait splash artwork used by `expo-splash-screen` without a fake progress indicator.
- `environments/` — world and biome artwork.
- `hominins/` — character artwork.
- `discoveries/` — discovery and event artwork.
- `scenarios/` — experiment artwork.
- `ui/` — product-specific UI imagery.

Keep app configuration references centralized in `app.config.ts`.
